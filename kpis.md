# KPIs del agente (no se carga al modelo; es referencia para el equipo)
| KPI | Cómo se mide |
|---|---|
| Preguntas respondidas | `kpis().preguntas` en consola |
| Tiempo promedio de respuesta | `kpis().tiempoPromedioSeg` |
| % resueltas correctamente | botones "Me sirvió" / "No me sirvió" |
| Satisfacción | utiles / (utiles + noUtiles) |
| Reducción de preguntas repetitivas | Comparar nº de consultas por correo/WhatsApp antes vs. después |
Nota: las métricas se guardan por navegador. Para consolidarlas, conecta un Google Form o Sheet (siguiente fase).
